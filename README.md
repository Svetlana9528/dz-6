# Домашнее задание к работе 6

## Условие задачи: 
Составить программу, которая проверяет, принадлежит ли заданная пользователем точка с координатами (x, y) заданным закрашенным (заштрихованным) областям, показанным на рисунках в табл., и выводит на экран сообщение.

# Алгоритм и блок-схема 

Алгоритм:

1. Начало.
2. Объявить переменные: x, y — вещественные числа для хранения координат точки; res — целое число (результат проверки); input_status — целое число (статус ввода).
3. Вывести на экран сообщение: «Для завершения программы введите координаты: 0 0».
4. Начало цикла с постусловием (do-while).
5. Вывести на экран сообщение: «Введите координаты точки (x, y): ».
6. Считать с клавиатуры значения x и y, записав статус успешности ввода в input_status.
7. Если input_status == 2, то:
	
	* Если x == 0 и y == 0, то прервать выполнение цикла (break, переход к шагу 9).
	
	* Вычислить логическое выражение принадлежности области:
res = (y >= 1 && y <= 5 && (2 * x - y + 9 >= 0) && (2 * x + y - 13 <= 0))
	
	* Если res == 1 (истинно), то вывести на экран сообщение «Результат: ПРИНАДЛЕЖИТ».
	
	* Иначе вывести на экран сообщение «Результат: НЕ ПРИНАДЛЕЖИТ».
8. Проверить условие продолжения цикла: пока input_status == 2. Если истинно — вернуться к шагу 5.
9. Вывести на экран сообщение: «Программа завершена.».
10. Конец

# Код:

``` c
#define _CRT_SECURE_NO_WARNINGS
#include <stdio.h>
#include <math.h>
#include <locale.h>

int check(float x, float y) {
    return (y >= 1 && y <= 5 && (2 * x - y + 9 >= 0) && (2 * x + y - 13 <= 0));
}

int main()
{
    setlocale(LC_ALL, ".UTF8");
    float x, y;
    int res;
    int input_status;

    printf("Для завершения программы введите координаты: 0 0\n\n");

    do {
        printf("Введите координаты точки (x, y): ");
        input_status = scanf("%f %f", &x, &y);

        if (input_status == 2) 
        {
            if (x == 0 && y == 0) 
            {
                break; 
            }
            res = check(x, y);
            if (res == 1) 
            {
                printf("Результат: ПРИНАДЛЕЖИТ\n\n");
            }
            else 
            {
                printf("Результат: НЕ ПРИНАДЛЕЖИТ\n\n");
            }
        }

    } while (input_status == 2);

    printf("Программа завершена.\n");
    return 0;
}
```

Контрольный пример :

 Точка(0, 2) — находится внутри области(выведет : ПРИНАДЛЕЖИТ области.)

 Точка(-4, 1) — левый нижний угол(выведет : ПРИНАДЛЕЖИТ области.).

 Точка(-1, -7) — находится ниже фигуры(выведет : НЕ ПРИНАДЛЕЖИТ области.).
